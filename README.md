# Weather by the climate score

An extension for [RPG Engine](https://github.com/stefanocaronia/rpg-engine): the weather where the party is changes each dawn by a roll of a climate score from 1, an extreme, to 6, the mildest, read on the table of the season, of hot deserts or of polar cold, with fog on cold mornings and afternoons that may turn on variable days. The master tells it as the sky; the engine keeps it.

Install it from a campaign with RPG Engine: `rpg package install weather`. The story needs to start on a day of the world (`config calendar-start "14 April"`), for the season.
